# -Api

星火 API 中转站开屏页。

主页面文件：`outputs/spark-relay-home.html`

包含星火火种主题视觉、圆润中文字体风格、暖色火焰主视觉、卖点卡片、按钮入口和使用说明。

## 使用说明

1. 打开 `outputs/spark-relay-home.html` 查看星火中转站首页。
2. 在页面下方的“使用说明”区域查看接入流程：获取 API Key、配置转发地址、发起模型请求。
3. 参考“接口调用示例”中的 `curl` 请求，把 `YOUR_API_KEY` 替换成自己的密钥，并把示例域名替换为实际中转站地址。
